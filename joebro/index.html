Features

One window, not ten apps.

Chat & documents

Write together

Chat with any model, with streaming, extended thinking and a real agent mode. Documents open right beside the conversation, including real Word .doc and .docx files, edited in place. Deep Research reads many sources and writes a cited report.

Memory

It remembers you

Brain is long-term memory filed on topic pages. Only what is relevant to the message at hand reaches the model. Add, edit, search or delete any memory, or explore it as a live brain map.

  • AI memory you can find, inspect and edit

Tools & MCP

Bring your own tools

Hand the agent any JSON endpoint as an API tool, add MCP servers over stdio, or drop in plugins. No MCP server is ever added for you, and the phone cannot add one either.

Blank slate. Your canvas

An adaptive glass interface over any wallpaper you choose, with built-in colour accents. Try it here: the dot in the menu bar re-tints this page.

JoeBro Mobile

Your agent, in your pocket

One chat that follows you, running on your own Mac. No cloud in the middle. Tasks run quietly in the background and only ping you when something changed. It is a source release: you build it yourself with Xcode.

Runs where you are

Your Mac. Or your Pi

The backend ships inside the Mac app and starts with it. That is the documented setup. I run mine headless on a Raspberry Pi so it stays reachable without leaving a Mac awake; that is my personal arrangement, not a supported installer.

Privacy & sovereignty

AI is better when it knows you. So keep it close

Stored on your Mac

Chats, documents and memory live on your machine. API keys are stored locally.

You pick the endpoint

Run local models with Ollama, or paste an API key. Prompts go to the endpoint you choose.

Cloak Mode, on by default

Detected keys, passwords, emails and account numbers are swapped for placeholders before a request leaves the backend.

Start with the data boundaryJoeBro stores workspace data on the Mac, but prompts go to the model endpoint the user selects. Cloak Mode replaces detected sensitive values; it does not make hosted inference local or guarantee every sensitive detail is removed. The documented iPhone setup pairs to a Mac that must remain open and awake.
