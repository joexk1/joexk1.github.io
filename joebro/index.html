Features

One window, not ten apps.

Write together

Chat with any model, with streaming, extended thinking and a real agent mode. Documents open right beside the conversation, including real Word .doc and .docx files, edited in place. Deep Research reads many sources and writes a cited report.

  • Editing documents beside the conversation in JoeBro
  • From a question to a cited report: Deep Research in JoeBro

It remembers you

Brain is long-term memory filed on topic pages. Only what is relevant to the message at hand reaches the model. Add, edit, search or delete any memory, or explore it as a live brain map. Phone memory is plain Markdown you can open and edit.

  • AI memory you can find, inspect and edit
  • Local AI means taking responsibility for your own data

Bring your own tools

Hand the agent any JSON endpoint as an API tool, add MCP servers over stdio, or drop in plugins. No MCP server is ever added for you, and the phone cannot add one either.

  • MCP tools in JoeBro: add only the capabilities you choose
  • Email and calendar with an AI assistant: keep the boundary visible

Blank slate. Your canvas

An adaptive glass interface over any wallpaper you choose, with built-in colour accents. Pick a swatch on the window: it re-themes the screenshot and this whole page.

Privacy & sovereignty

AI is better when it knows you. So keep it close

What you type · on your Mac

Book the Lisbon flights on my card 4929 1234 5678 9012, the airline password is hunter2-lisboa, and use my API key sk-proj-7Hf2kQa9Lx for the price check.

Cloak Mode
What the model receives

Book the Lisbon flights on my card 4929 1234 5678 9012[CARD NUMBER], the airline password is hunter2-lisboa[PASSWORD], and use my API key sk-proj-7Hf2kQa9Lx[API KEY] for the price check.

Illustrative example. Cloak Mode is on by default and swaps detected values for placeholders before any request leaves the backend, for every model endpoint, local ones included. Redaction is a guardrail, not a guarantee.

Stored on your Mac

Chats, documents and memory live on your machine. API keys are stored locally.

You pick the endpoint

Run local models with Ollama, or paste an API key. Prompts go to the endpoint you choose.

Cloak Mode, on by default

Detected keys, passwords, emails and account numbers are swapped for placeholders before a request leaves the backend.

Start with the data boundaryJoeBro stores workspace data on the Mac, but prompts go to the model endpoint the user selects. Cloak Mode replaces detected sensitive values; it does not make hosted inference local or guarantee every sensitive detail is removed. The documented iPhone setup pairs to a Mac that must remain open and awake.
